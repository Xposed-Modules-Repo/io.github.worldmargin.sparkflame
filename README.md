# 星火燎原 · 抖音自动续火花

一个 LSPosed 模块：注入抖音进程，**自动给「今天还没互动」的会话续火花** —— 发一条你自己写的文案。
文案是一段 JavaScript，由「模板 + 两层变量 + 宏 + 自定义函数」组合出来，目标是「每天自动续，但话说得像真人说的」。

作用域：`com.ss.android.ugc.aweme`（抖音）

源码：<https://gitee.com/WorldMargin/SparkFlame>（主）· <https://github.com/WorldMargin/SparkFlame>（镜像）
问题反馈：<https://gitee.com/WorldMargin/SparkFlame/issues>
许可证：Apache-2.0

---

## 它做什么

抖音的火花需要双方每天有互动。模块会在**抖音启动 / 回到前台 / 跨天时**扫一遍会话，把「今天还没互动」的挑出来，
按你配置的脚本生成文案发过去；每个会话每天最多发一条。

- **待发**：今天还没发过 → 会发
- **待对方回复**：今天已经发过、火花还是灰的（对方还没回） → 不重复发
- **今日已续**：今天已经互动过 → 跳过
- **待重燃**：火花断在恢复期 → 按抖音判定处理

打开抖音、跨天补跑、手动发送之后，模块会把会话快照**自动写回管理界面**，不用打开 App 也能看到最新状态。

## 功能

- **模板**：内置模板（空白 / 续火花 / [续火花吧] / 按时问候 / 火花天数打卡 / 简短提醒）+ 自定义模板
- **变量（两层）**：模板一套、会话一套；同名覆盖、空值回落、顺序求值、出错不中断
- **宏**：挂在模板 / 会话上的后置脚本，可动态挂载 / 卸载，预览时跳过
- **标签**：多对多，只用于整理与筛选（不改变发送资格）；支持多选并集、来源单选与 AND 组合
- **脚本**：`ctx.result` 只表达内容，空列表 = 不发；`getAllConversation` 支持字段筛选与 `tags.include/except`
- **编辑器**：CodeMirror，内置 `ctx.*` 补全、一键格式化、粘贴还原、原生长按
- **可观测**：预览、试算、宿主状态、发送结果三态回执（Succeed / Skipped / Failed）
- **新手引导**：右下角可拖动的悬浮胶囊，基础 / 进阶两条路线按顺序解锁，目标控件蓝色描边轮流高亮

## 安装

1. 安装 APK，在 LSPosed 里启用模块并勾选作用域「抖音」
2. 强制停止抖音后重新打开
3. 打开一次模块 App：确认「设置 → 宿主状态」有内容，说明已注入
4. 在「续火花」页选目标、写模板，点「发送」或等自动发送

> 升级前建议先在「设置 → 配置」导出备份。
